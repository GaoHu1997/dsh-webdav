# 0033 「保存密码」移进密码字段的标签行，删掉那句说明

- 状态：已接受
- 日期：2026-10-19

## 背景

「保存密码」管的是 WebDAV 密码，不是口令。但卡片上它原本在「服务器」小节的最末尾、自己占一行，位置在**口令字段之下**，还带着一句 `rememberPasswordHint`（「关掉后，密码只在本次运行内使用，不写入本机」）。[0003](0003-secrets-in-state-file.md) 早已把这条记成已知误解：用户会以为关掉它连口令也不落盘。

用户 2026-10-19 提出的改法：把复选框放到「密码」这个小标题后面，让位置自己说明它管的是哪个字段，这样连那句说明都不用加。

当时的 `.toggleRow` 也确实在帮倒忙：它是整张小节里唯一一个字段级的选项，却因为独立成行、还带一条 `border-top`，看起来像管整个小节（地址、密码、口令）的开关。

## 决策

复选框移进密码字段的标签行：

```tsx
<div className={css.field}>
  <div className={css.labelRow}>
    <label className={css.fieldLabel} htmlFor="webdav-sync-password">{t('passwordLabel')}</label>
    <Checkbox
      checked={state.rememberPassword}
      label={t('rememberPassword')}
      onChange={(next) => props.toggle('rememberPassword', next)}
    />
  </div>
  <Input id="webdav-sync-password" ... />
</div>
```

`rememberPasswordHint` 随之删除：`WebdavSyncKey` 联合类型里的一行、`zh` 与 `en` 各一条，`t()` 少一个调用点。`.toggleRow` 改名 `.labelRow`（`display: flex; align-items: center; justify-content: space-between; gap: 10px`），保留把复选框压到 12px / 14px 的两条元素选择器（与 `.partRow label` 同一手法，理由见 [0031](0031-card-layout-and-chinese-messages.md)），并新增 `color: var(--dsw-alias-label-secondary)`：它现在和「密码」同处一行，就该和字段标签同色，而不是用组件默认的 `label-primary` 抢在字段名前面。

标签行里的两件东西分站两端（`justify-content: space-between`）：用户第一版看到的是紧挨着的「密码 ☑ 保存密码」，反馈「挤到一起不好看」。分开之后，「密码」仍贴着字段列的左边缘（与上方「用户名」对齐），复选框落在该列的右边缘、与输入框的右端齐平，中间留白把「这是字段名」和「这是这个字段的一个选项」分开了。`gap: 10px` 保留，但只在窄到两端挤不下时才起作用（它是不被压到一起的下限，不是两端的距离）。

放在**标签行**而不是输入框下方，是因为 `.grid` 是两列：输入框下方多一行会让「密码」输入框比「用户名」输入框低一截；标签行的高度（18px）与原来的标签相同，两列输入框仍然齐平。

被否决的备选：

- **只挪位置、保留说明**。位置已经说明它管哪个字段，那句话就只剩复述；0031 的判据是「一句话若不改变用户接下来的动作，就不留在卡片上」。
- **放到密码输入框下方**。离字段一样近，但用户说的是「小标题后面」，且如上，两列输入框会错开。
- **把说明改成「口令总是保存在本机」**。那是在为一个不该存在的问题写文案：复选框不再挨着口令字段，问题本身就没了。
- **把文案改成「保存 WebDAV 密码」**。更长，而且在这张只有密码和口令两个密钥的卡片里，「密码」没有歧义。
- **标签和复选框紧挨着靠左放**。这是第一版的做法，被用户否掉：「需要右对齐，挤到一起不好看」。两者贴在一起时读起来像一个长词（「密码保存密码」），右对齐让复选框自带一个「这是该字段的选项」的位置信号，也和下方输入框的右端对齐。

## 影响

正面：

- 卡片少一行字、少一条分隔线，视图从上到下是「地址 → 用户名 / 密码（含保存开关）→ 口令」。
- 0003 记下的那个误解消失：复选框就在它管的那个字段上，不需要读者做一次位置推理。
- 原来那条 `border-top` 会让「口令」看起来属于上面的开关组，现在没有这层结构暗示了。
- 复选框站在字段列的右边缘，和它下面的密码输入框右端齐平；两端对齐之后，「密码」和「保存密码」不再连成一个长词。

负面：

- **「关掉后密码只在本次运行内可用、重启后要重填」不再写在卡片上**。这是用户明确不要的那句；行为本身没变（[0019](0019-session-password-not-remembered.md)），只是不再解释。
- 标签行的高度依赖复选框被压到 14px 的盒子；组件换根元素或 `.checkbox` 的字号变大时，它会高过 18px，两列输入框随之错开——与 0031 记的「复选框那行字的字号不归本卡片所有」是同一类风险。
- 改动只落在浏览器半边，`lib/client.js` 是构建产物：已经装到机器上的旧版本要重新发布或重装才会看到。
