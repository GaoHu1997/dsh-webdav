# 0070 — 手动备份去掉图标，直接点击导入导出整行

- 状态：已接受
- 日期：2026-10-22
- 相关：[0069](0069-box-arrows-for-backup-icons.md)、[0067](0067-part-order-and-backup-icons.md)、[0060](0060-manual-backup.md)

## 背景

用户要求移除导入、导出的图标，直接点击这两行。原来的入口是紧跟标题的独立图标按钮，说明文字还引导用户点击图标，与新的交互不符。

## 决策

- 两行各改为一个原生 `button type="button"`，覆盖整行宽度，标题与说明都在按钮内；点击标题、说明或行内空白均沿用原先的展开/收起动作。表单仍在按钮外，不产生嵌套交互控件。
- 保留 `disabled`、`aria-label`、`aria-expanded`、`aria-controls`，由原生按钮提供 Tab 聚焦与 Enter/空格激活，忙碌时不可操作。不采用仅在 `div` 上添加点击处理的方案，避免自行重实现键盘与禁用语义。
- 删除图标组件及专用标题/图标样式；保留无边框文字布局，增加整行悬停反馈并复用已有焦点环。不同于只让标题可点，整行按钮提供与用户请求一致的点击范围。
- 同步更新中英文导出提示、README 与回归测试。本条取代 0067–0069 中手动备份入口的图标形状，其他同步顺序、密码展示和备份协议不变。

## 影响

- 入口不再依赖图标含义，点击范围更大；鼠标悬停和键盘聚焦有明确反馈。失去原先图标的方向提示，由现有标题与说明承担含义。
- 导入导出只改变入口，不改变加密、文件选择、写盘、确认与结果展示，也不改变版本号或依赖。
- 测试覆盖两行无 SVG、原生按钮语义、展开状态、忙碌禁用以及整行样式；仍需构建客户端后由宿主加载新产物。
